# Stage 1
This stage contains four artefacts for analysis.
Two of the artefacts are provided as **PDF files** and two are provided as **.eml files**.
## .eml Files
An '.eml' file is an email message saved in its original email format. Unlike a screenshot or PDF of an email, it contains the underlying email data, including message headers and other metadata that may be useful during an investigation.
## Suspicious or Malicious Files
Any suspicious or potentially malicious files referenced within the supplied artefacts are **not provided for analysis** as part of this exercise.
In a real-world investigation, potentially malicious files should be handled and analysed within an appropriately protected and isolated sandbox environment. Where appropriate, detailed malware analysis would be conducted by a trained specialist.
The '.eml' files should be downloaded and opened using an appropriate email client to examine their contents.
> **Important:** Treat all supplied artefacts as investigative material. Do not assume that information contained within an artefact is accurate or benign.
